一个用于 **THE KING OF FIGHTERS XIV**（Steam，PC）的读屏 MOD。它会用你已经在用的读屏软件
（NVDA、JAWS 等）念出菜单、剧情、各种列表和画面上的文字，让这款游戏在看不见的情况下也能玩。

它使用**游戏当前运行的语言**朗读，十一种语言都一样，因为它说的几乎全是游戏自己的文本，而不是
MOD 自己的词句。

## 它会读的内容

- **菜单与设置**：你进入的画面、当前选中的项目及其说明；一项设置的名称、当前的值，以及改动之后
  变成了什么。
- **操作设置**：从选项和暂停菜单进入的操作设置画面 —— 每位玩家使用的设备、每个动作的分配，以及分配
  本身：接下的按键或按钮，和被挤掉的那个。键盘按键按游戏写出的样子朗读；手柄按钮则根据游戏传给该画面
  的分配数据命名 —— 这是本版本的新功能，仍在核对中。
- **剧情模式**：每一句对话和每一个结局。本作没有配音，没有它就无从得知内容。
- **指令表**：招式如何发出，提供五种写法（按 F10 切换）：游戏自己的说法、街机、街机简写、FGC、
  FGC 简写。
- **挑战与教学**：要求的连段，一步一步；以及每一课的文字，指令就留在句子里。
- **角色选择**：角色、自定义面板（颜色与服装），以及出场顺序画面，包括对手是谁和三打一的 Boss
  关卡。
- **玩家数据**：记录、排行榜、个人资料与名片、角色记录与数据。
- **图鉴**：插画、物品、影片和声音，以及还没解锁的部分。
- **对战中的数值（按需朗读）**：体力、能量槽和计时赛的用时，直接取自游戏自己的 HUD（见下方按键
  表）。
- **联机**：菜单、排名对战（含首次询问与搜索设置）、对战列表、录像（连同对战双方的队伍），以及
  联机资料。
- **提示、确认和系统消息**，出现在哪里都读。

按键提示、排版占位和页码装饰**故意不读**。

## 目前还没覆盖的部分

- **联机房间**：自由对战和联机训练的房间 —— 玩家列表、排队和等待画面。
- **联机对战前后的画面**：找到对手的画面，以及带排名分数的联机结算。两者都需要有另一位玩家才能
  到达，因此都还没验证过。
- **观看录像**：播放时的操作。

## 需要什么

- KOF XIV 的 Steam（PC）版。
- 正在运行的读屏软件（NVDA、JAWS 等）。MOD 通过
  [PRISM](https://github.com/ethindp/prism) 朗读，使用当时启用的那一个。
- Windows x64。

## 安装

把三个文件复制到游戏文件夹，也就是 `kofxiv.exe` 旁边：

```
winmm.dll     MOD 本体
prism.dll     PRISM
tolk.dll      PRISM 的 NVDA/JAWS 后端
```

其他什么都不会变，也不会修改或改名任何游戏文件。卸载就是删掉这三个文件。

MOD 能被载入，是因为游戏会用到 `winmm.dll`；放在游戏文件夹里的这一份会把该库的所有函数转交给
`System32` 里真正的那一份，所以进程里的其他部分不会察觉它的存在。

## 按键

| 按键 | 作用 |
|------|------|
| 上 / 下 | 浏览画面保存的内容 —— 指令表、分数表、制作名单。有对话框打开时，移动它的选项 |
| F1 | 念出画面保存的全部内容。有对话框时：正文、它显示的内容（录像的双方玩家、日期和模式）以及当前选项 |
| F2 | 往回一步。有对话框时：正文和当前选项 |
| F3 | 往前一步。有对话框时：它针对所问事项显示的内容 |
| 右摇杆（对战中） | 按画面上槽条的位置：左边是 1P 体力，右边是 2P 体力，上是 1P 能量槽，下是 2P 能量槽 |
| 按下右摇杆（对战中） | 双方一起：“PLAYER 1, 62%, POWER 2, PLAYER 2, 40%, POWER 1”。计时赛中则是目前的用时 |
| 右摇杆（非对战时） | 手柄上的 F1 至 F3：上相当于 F2，下相当于 F3，左右相当于 F1，按下则像 F10 一样切换写法。在挑战或教学中保持如此，按下也一样：那里方向属于角色，指令比槽条更重要 |
| F10 | 在五种写法之间切换指令的念法 |
| F11，或手柄上两个摇杆同时按下 | 关闭整个朗读器，再按一次开启。关闭时什么都不念，只有这两个按键仍然响应；每次启动都是开启状态 |
| F7 | 停止朗读 |
| F8 | 说出 MOD 找到的读屏软件名称 —— 能听到任何声音就说明 MOD 在工作 |
| F9 | 静默地在日志里标记此刻：“问题在这里” |
| F5 | 诊断：导出接下来的翻译，并向影片询问 MOD 读不到的内容 |
| F6 | 开启或关闭诊断日志（默认开启） |

在**生存模式**中，F1 至 F3 和右摇杆的方向会以百分比念出剩余体力；在**计时赛**中，则以结算画面
的格式念出目前的用时。

画面保存的内容会停在两端，不会绕回开头：越过最后一段不会有声音，退到第一段之前也不会。那份安静
就是开头和结尾的标记 —— 连段的各个步骤、课程的各个句子、表格的各行。作为一整块保存的内容没有两
端，每次询问都会整段念出。

**MOD 没有自己的话。** 它说的全是游戏的文本（保持游戏的语言）或一个名称。该说自己的话时 —— 按
下朗读键却没有内容可读、在日志里留下标记 —— 它什么都不说，安静就是回答。开关类的操作用游戏自己
表示开和关的词来回答。

## MOD 会写入什么

和日志放在一起的 `KofXIVReader.learned` 保存着游戏只展示一次的少数信息：哪些角色在自定义面板里
有服装那一行。游戏只在第一次需要时画出那一行，之后再也不提，所以看见是唯一的知道方式。记下来之
后，MOD 只会慢一次，而不是每次启动都慢。删掉这个文件，它会重新学一遍。

旁边的 `KofXIVReader.settings` 保存的不是游戏展示的内容，而是你自己的选择：目前只有念出指令所用
的写法。朗读器被关掉这件事刻意不保存——记住它的 MOD 会让游戏在启动时一声不响，又说不出原因。

## 报告问题

在游戏里按 **F6** 打开日志，在读错的那一刻按 **F9**，然后正常退出。日志是游戏文件夹里的
`KofXIVReader.log`，上一次的会留在旁边，名为 `KofXIVReader.prev.log`。它记录了游戏显示了什么、
写在哪个字段、来自哪个画面，以及 MOD 对此说了什么 —— 足以看出它本该说什么。不需要你把听到的内容
写下来：日志里已经有准确的原文。
