**THE KING OF FIGHTERS XIV**(스팀, PC)용 스크린 리더 모드입니다. 메뉴, 스토리, 각종 목록, 화면
의 텍스트를 이미 쓰고 있는 스크린 리더(NVDA, JAWS 등)로 읽어 줍니다. 화면을 보지 않고도 게임을
할 수 있게 하는 것이 목적입니다.

읽어 주는 언어는 **게임이 실행 중인 언어**이며, 열한 개 중 어느 것이든 마찬가지입니다. 모드가
말하는 내용은 거의 전부 모드의 말이 아니라 게임 자신의 텍스트이기 때문입니다.

## 읽어 주는 것

- **메뉴와 설정**: 들어간 화면, 선택된 항목과 그 설명. 설정의 이름, 현재 값, 그리고 바꾼 결과.
- **조작 설정**: 옵션과 일시 정지 메뉴에서 여는 조작 설정 화면 — 각 플레이어가 쓰는 기기, 각 동작에
  할당된 키나 버튼, 그리고 할당 자체: 가져간 키나 버튼과 밀려난 것. 키보드 키는 게임이 쓰는 대로
  읽고, 패드 버튼은 게임이 화면에 넘기는 할당 정보로 이름을 붙입니다. 이번 버전의 새 기능이며 아직
  확인 중입니다.
- **스토리 모드**: 모든 대사와 모든 엔딩. 이 게임에서는 음성이 없어서, 이것 없이는 내용을 알
  방법이 없습니다.
- **커맨드 리스트**: 기술을 쓰는 방법을 다섯 가지 표기로(F10으로 전환): 게임 자신의 표현, 아케
  이드, 아케이드 간략, FGC, FGC 간략.
- **트라이얼과 튜토리얼**: 요구되는 콤보를 한 단계씩, 각 레슨의 문장을 커맨드가 들어간 그대로.
- **캐릭터 선택**: 캐릭터, 커스터마이즈 창(색과 코스튬), 그리고 순서 화면(상대가 누구인지, 3대
  1 보스 단계 포함).
- **플레이어 데이터**: 기록, 랭킹, 내 프로필과 카드, 캐릭터 기록과 데이터.
- **갤러리**: 일러스트, 아이템, 영상, 사운드, 그리고 아직 얻지 못한 것.
- **대전 중의 수치(요청할 때만)**: 체력, 파워 게이지, 타임 어택의 시간. 게임 자신의 HUD에서 읽
  습니다(아래 키 목록 참고).
- **온라인**: 메뉴, 랭크 매치(첫 질문과 검색 설정 포함), 대전 목록, 리플레이(대전한 팀까지),
  온라인 프로필.
- **알림, 확인, 시스템 메시지**(어느 화면이든).

버튼 안내, 레이아웃 여백, 페이지 숫자 장식은 **의도적으로** 읽지 않습니다.

## 아직 다루지 않는 것

- **온라인 방**: 자유 대전과 온라인 트레이닝의 로비 — 참가자 목록, 순서 대기, 대기 화면.
- **온라인 대전 전후의 화면**: 상대를 찾은 화면과 랭크 점수가 있는 온라인 결과. 둘 다 상대가
  있어야 도달하므로 검증하지 못했습니다.
- **리플레이 감상**: 재생 중의 조작.

## 필요한 것

- KOF XIV 스팀(PC) 버전.
- 실행 중인 스크린 리더(NVDA, JAWS 등). 모드는
  [PRISM](https://github.com/ethindp/prism)을 통해 말하며, 그때 활성화된 것을 사용합니다.
- Windows x64.

## 설치

게임 폴더(`kofxiv.exe`와 같은 위치)에 파일 세 개를 복사합니다.

```
winmm.dll     모드 본체
prism.dll     PRISM
tolk.dll      PRISM의 NVDA/JAWS 연결
```

그 밖에는 아무것도 바뀌지 않으며, 게임 파일을 고치거나 이름을 바꾸지도 않습니다. 제거는 이 세
파일을 지우면 됩니다.

모드가 불려오는 이유는 게임이 `winmm.dll`을 쓰기 때문입니다. 게임 폴더에 둔 쪽은 그 라이브러리
의 모든 함수를 `System32`의 진짜 쪽으로 넘기므로, 프로세스의 다른 부분은 존재를 알아채지 못합
니다.

## 키

| 키 | 하는 일 |
|----|---------|
| 위 / 아래 | 화면이 가지고 있는 내용(커맨드 리스트, 점수표, 크레딧)을 훑습니다. 대화창이 열려 있으면 그 선택을 움직입니다 |
| F1 | 화면이 가지고 있는 내용을 전부 말합니다. 대화창이 열려 있으면 본문, 그 내용(리플레이의 플레이어, 날짜, 모드), 선택된 항목 |
| F2 | 한 단계 뒤로. 대화창이 열려 있으면 본문과 선택된 항목 |
| F3 | 한 단계 앞으로. 대화창이 열려 있으면 묻고 있는 대상에 대해 표시된 내용 |
| 오른쪽 스틱(대전 중) | 화면의 게이지 위치 그대로: 왼쪽은 1P의 체력, 오른쪽은 2P의 체력, 위는 1P의 파워 게이지, 아래는 2P의 파워 게이지 |
| 오른쪽 스틱 누르기(대전 중) | 둘을 한꺼번에: "PLAYER 1, 62%, POWER 2, PLAYER 2, 40%, POWER 1". 타임 어택에서는 지금까지의 시간 |
| 오른쪽 스틱(대전 밖) | 패드용 F1~F3: 위가 F2, 아래가 F3, 좌우가 F1, 누르기는 F10처럼 표기를 바꿉니다. 트라이얼이나 레슨 중에도 그대로이고 누르기도 포함합니다. 거기서는 방향이 캐릭터의 것이고, 게이지보다 커맨드가 중요합니다 |
| F10 | 커맨드를 말하는 방식을 다섯 가지 표기 사이에서 바꿉니다 |
| F11, 또는 패드의 양쪽 스틱 누르기 | 리더 전체를 끄고, 다시 켭니다. 꺼져 있으면 아무 말도 하지 않지만 이 두 가지는 계속 반응하며, 실행할 때마다 켜진 상태로 시작합니다 |
| F7 | 말하기를 멈춥니다 |
| F8 | 찾은 스크린 리더의 이름을 말합니다. 무언가 들린다면 모드는 동작 중입니다 |
| F9 | 지금 시점을 로그에 조용히 표시합니다("문제는 여기") |
| F5 | 진단: 다음 번역들을 기록하고, 모드가 읽을 수 없는 것을 무비에 물어봅니다 |
| F6 | 진단 로그를 켜거나 끕니다(기본값은 켜짐) |

**서바이벌**에서는 F1~F3과 오른쪽 스틱의 방향이 남은 체력을 백분율로 말합니다. **타임 어택**에
서는 결과 화면과 같은 형식으로 지금까지의 시간을 말합니다.

화면이 가지고 있는 내용은 양 끝에서 멈추고 처음으로 돌아가지 않습니다. 마지막 다음으로 가려 해
도 아무 말이 없고, 처음 앞으로 돌아가려 해도 그렇습니다. 그 침묵이 시작과 끝의 표시입니다(콤보
의 각 단계, 레슨의 각 문장, 표의 각 줄). 하나의 덩어리로 가지고 있는 것은 끝이 없으며, 요청할
때마다 전체를 말합니다.

**모드에는 자기만의 말이 없습니다.** 말하는 내용은 모두 게임의 텍스트(게임의 언어 그대로)이거
나 고유한 이름입니다. 자기 말을 해야 할 상황 — 읽을 것이 없는데 읽기 키를 눌렀을 때, 로그에 표
시를 남길 때 — 에는 아무 말도 하지 않고, 침묵이 답이 됩니다. 켜고 끄는 항목은 게임 자신의 말로
답합니다.

## 모드가 쓰는 파일

로그와 같은 위치의 `KofXIVReader.learned`에는 게임이 한 번만 보여 주는 몇 가지가 들어갑니다.
커스터마이즈 창에 코스튬 줄이 있는 캐릭터가 누구인지입니다. 게임은 그 줄을 필요해진 첫 순간에만
그리고 그 뒤로는 언급하지 않으므로, 보는 것이 아는 유일한 방법입니다. 적어 두면 모드가 뒤처지는
것은 한 번뿐이고, 켤 때마다가 아닙니다. 파일을 지우면 전부 다시 배웁니다.

그 옆의 `KofXIVReader.settings`에는 게임이 보여 준 것이 아니라 당신이 고른 것이 들어갑니다. 지금
은 커맨드를 읽는 표기법뿐입니다. 꺼 둔 상태는 일부러 저장하지 않습니다. 그것을 기억하는 모드는
이유도 말해 주지 못하면서 조용한 게임을 시작하게 되니까요.

## 문제 보고

게임에서 **F6**으로 로그를 켜고, 잘못 읽는 순간에 **F9**를 누른 뒤 평소처럼 종료하세요. 로그는
게임 폴더의 `KofXIVReader.log`이고, 지난 세션은 `KofXIVReader.prev.log`로 함께 남습니다. 게임이
무엇을 표시했는지, 어떤 필드인지, 어느 화면에서 왔는지, 그리고 모드가 그에 대해 무엇을 말했는지
가 기록되어 있어, 무엇을 말해야 했는지 판단할 수 있습니다. 들은 내용을 적을 필요는 없습니다. 로
그에 정확한 문장이 남아 있습니다.
