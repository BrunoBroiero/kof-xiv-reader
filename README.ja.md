**THE KING OF FIGHTERS XIV**（Steam、PC）用のスクリーンリーダー対応MODです。メニュー、ストー
リー、各種リスト、画面上のテキストを、あなたが普段使っているスクリーンリーダー（NVDA、JAWS
など）で読み上げます。画面を見なくても遊べるようにするためのものです。

読み上げは**ゲームが動作している言語**で行われます。11言語のどれであっても同じです。MODが話す
内容のほとんどは、MOD自身の言葉ではなくゲーム自身のテキストだからです。

## 読み上げる内容

- **メニューと設定**：入った画面、選択中の項目とその説明。設定の名前、現在の値、変更後の値。
- **ストーリーモード**：すべての台詞とすべてのエンディング。このゲームでは音声がないため、これ
  がなければ内容を知る方法がありません。
- **コマンドリスト**：技の出し方を5つの表記で（F10で切り替え）。ゲーム自身の言葉、アーケード、
  アーケード簡易、FGC、FGC簡易。
- **トライアルとチュートリアル**：要求されているコンボを一手ずつ、各レッスンの文章をコマンド入
  りのまま。
- **キャラクター選択**：キャラクター、カスタマイズ画面（カラーとコスチューム）、順番決め画面
  （対戦相手、3対1のボス戦も含む）。
- **プレイヤーデータ**：記録、ランキング、自分のプロフィールとカード、キャラクター記録とデータ。
- **ギャラリー**：イラスト、アイテム、ムービー、サウンド。未入手のものも分かります。
- **試合中の数値（要求したときだけ）**：体力、パワーゲージ、タイムアタックの時間。ゲーム自身の
  HUDから読み取ります（下のキー一覧を参照）。
- **オンライン**：メニュー、ランクマッチ（初回の確認と検索設定を含む）、対戦リスト、リプレイ
  （対戦したチームも）、オンラインプロフィール。
- **通知、確認、システムメッセージ**（どの画面であっても）。

ボタンの操作ヒント、レイアウトの余白、ページ番号の飾りは、意図的に読み上げ**ません**。

## まだ対応していない部分

- **オンラインの部屋**：フリーマッチとオンライントレーニングのロビー。参加者一覧、順番待ち、待
  機画面。
- **オンライン対戦の前後の画面**：対戦相手が見つかった画面と、ランクポイント付きのオンライン結
  果。どちらも相手が必要なため、未検証です。
- **リプレイの再生**：再生中の操作。

## 必要なもの

- KOF XIV の Steam（PC）版。
- 動作中のスクリーンリーダー（NVDA、JAWS など）。MODは
  [PRISM](https://github.com/ethindp/prism) を通して話し、その時点で有効なものを使います。
- Windows x64。

## インストール

ゲームフォルダー（`kofxiv.exe` と同じ場所）に次の3つのファイルをコピーします。

```
winmm.dll     MOD本体
prism.dll     PRISM
tolk.dll      PRISM の NVDA/JAWS 用バックエンド
```

ほかには何も変わりません。ゲームのファイルを書き換えたり名前を変えたりもしません。アンインス
トールはこの3つを削除するだけです。

MODが読み込まれるのは、ゲームが `winmm.dll` を使っているからです。ゲームフォルダーに置いた方
は、そのライブラリのすべての関数を `System32` にある本物へ渡すので、プロセス内のほかの部分は
その存在に気づきません。

## キー

| キー | 動作 |
|------|------|
| 上 / 下 | 画面が保持している内容（コマンドリスト、得点表、クレジット）をたどります。ダイアログが開いているときは、その選択を動かします |
| F1 | 画面が保持している内容をすべて読み上げます。ダイアログが開いているときは、本文、その内容（リプレイのプレイヤー、日付、モード）、選択中の項目 |
| F2 | 1つ戻ります。ダイアログが開いているときは、本文と選択中の項目 |
| F3 | 1つ進みます。ダイアログが開いているときは、質問の対象について表示されている内容 |
| 右スティック（試合中） | 画面上のゲージの位置どおりに。左は1Pの体力、右は2Pの体力、上は1Pのパワーゲージ、下は2Pのパワーゲージ |
| 右スティック押し込み（試合中） | 両者まとめて：「PLAYER 1, 62%, POWER 2, PLAYER 2, 40%, POWER 1」。タイムアタックでは、ここまでの時間 |
| 右スティック（試合以外） | パッドでのF1〜F3。上がF2、下がF3、左右がF1、押し込みはF10と同じく表記の切り替えです。トライアルやレッスン中もこのままで、押し込みも含みます。そこでは方向はキャラクターのものであり、ゲージよりコマンドが重要です |
| F10 | コマンドの言い方を5つの表記の間で切り替えます |
| F4 | メニュー読み上げのオン・オフ |
| F7 | 読み上げを止めます |
| F8 | 見つかったスクリーンリーダーの名前を言います。何か聞こえれば、MODは動いています |
| F9 | ログに現在の時点を無音で記録します（「問題はここ」） |
| F5 | 診断：次の翻訳を書き出し、MODが読めないものをムービーに尋ねます |
| F6 | 診断ログのオン・オフ（初期状態はオン） |

**サバイバル**では、F1〜F3と右スティックの方向が残り体力を百分率で読み上げます。**タイムアタッ
ク**では、結果画面と同じ形式で経過時間を読み上げます。

画面が保持している内容は端で止まり、先頭に戻りません。最後の先へ進もうとしても何も言わず、最
初より前に戻ろうとしても何も言いません。その沈黙が始まりと終わりの印です（コンボの各手順、レ
ッスンの各文、表の各行）。ひとまとまりとして保持されているものには端がなく、求めるたびに全体
を読み上げます。

**MODは自分の言葉を持ちません。** 話す内容はすべてゲームのテキスト（ゲームの言語のまま）か、
固有名です。自分の言葉を言う必要がある場面——読み上げるものがないのに読み上げキーを押したとき、
ログに印を付けたとき——では何も言わず、沈黙が答えになります。オン・オフの切り替えは、ゲーム自身
の言葉で答えます。

## MODが書き込むファイル

ログと同じ場所にある `KofXIVReader.learned` は、ゲームが一度しか見せないことを記録します。具体
的には、カスタマイズ画面にコスチューム欄があるのはどのキャラクターか、です。ゲームはその欄を必
要になった最初の一度だけ描画し、その後は触れないため、見ることが知る唯一の方法です。記録してお
けば、MODが遅れるのは一度だけで、起動のたびではなくなります。このファイルを削除すると、すべて
を再び学習します。

## 問題の報告

ゲーム中に **F6** でログを有効にし、読み上げがおかしかった瞬間に **F9** を押して、通常どおり終
了してください。ログはゲームフォルダーの `KofXIVReader.log` で、前回の分は
`KofXIVReader.prev.log` として残ります。ゲームが何を表示したか、どのフィールドか、どの画面から
来たか、それに対してMODが何を言ったかが記録されており、本来何と言うべきだったかを判断できます。
聞こえた内容を書き取る必要はありません。ログに正確な文言が残っています。
