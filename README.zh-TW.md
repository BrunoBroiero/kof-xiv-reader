一個用於 **THE KING OF FIGHTERS XIV**（Steam，PC）的螢幕閱讀器 MOD。它會用你已經在用的螢幕閱讀
器（NVDA、JAWS 等）念出選單、劇情、各種清單和畫面上的文字，讓這款遊戲在看不見的情況下也能玩。

它使用**遊戲目前執行的語言**朗讀，十一種語言都一樣，因為它說的幾乎全是遊戲自己的文字，而不是
MOD 自己的詞句。

## 它會讀的內容

- **選單與設定**：你進入的畫面、目前選取的項目及其說明；一項設定的名稱、目前的值，以及改動之後
  變成了什麼。
- **操作設定**：從選項和暫停選單進入的操作設定畫面 —— 每位玩家使用的裝置、每個動作的指派，以及指派
  本身：接下的按鍵或按鈕，和被擠掉的那個。鍵盤按鍵依遊戲寫出的樣子朗讀；手把按鈕則依遊戲傳給該畫面
  的指派資料命名 —— 這是本版本的新功能，仍在核對中。
- **劇情模式**：每一句對話和每一個結局。本作沒有配音，沒有它就無從得知內容。
- **指令表**：招式如何發出，提供五種寫法（按 F10 切換）：遊戲自己的說法、大型電玩、大型電玩簡
  寫、FGC、FGC 簡寫。
- **挑戰與教學**：要求的連段，一步一步；以及每一課的文字，指令就留在句子裡。
- **角色選擇**：角色、自訂面板（顏色與服裝），以及出場順序畫面，包括對手是誰和三打一的 Boss
  關卡。
- **玩家資料**：紀錄、排行榜、個人資料與名片、角色紀錄與資料。
- **圖鑑**：插畫、物品、影片和聲音，以及還沒解鎖的部分。
- **對戰中的數值（按需朗讀）**：體力、能量槽和計時賽的用時，直接取自遊戲自己的 HUD（見下方按鍵
  表）。
- **連線**：選單、排名對戰（含首次詢問與搜尋設定）、對戰清單、錄影（連同對戰雙方的隊伍），以及
  連線資料。
- **提示、確認和系統訊息**，出現在哪裡都讀。

按鍵提示、排版佔位和頁碼裝飾**刻意不讀**。

## 目前還沒涵蓋的部分

- **連線房間**：自由對戰和連線練習的房間 —— 玩家清單、排隊和等待畫面。
- **連線對戰前後的畫面**：找到對手的畫面，以及帶排名分數的連線結算。兩者都需要有另一位玩家才能
  抵達，因此都還沒驗證過。
- **觀看錄影**：播放時的操作。

## 需要什麼

- KOF XIV 的 Steam（PC）版。
- 正在執行的螢幕閱讀器（NVDA、JAWS 等）。MOD 透過
  [PRISM](https://github.com/ethindp/prism) 朗讀，使用當時啟用的那一個。
- Windows x64。

## 安裝

把三個檔案複製到遊戲資料夾，也就是 `kofxiv.exe` 旁邊：

```
winmm.dll     MOD 本體
prism.dll     PRISM
tolk.dll      PRISM 的 NVDA/JAWS 後端
```

其他什麼都不會變，也不會修改或更名任何遊戲檔案。卸載就是刪掉這三個檔案。

MOD 能被載入，是因為遊戲會用到 `winmm.dll`；放在遊戲資料夾裡的這一份會把該程式庫的所有函式轉交
給 `System32` 裡真正的那一份，所以行程裡的其他部分不會察覺它的存在。

## 按鍵

| 按鍵 | 作用 |
|------|------|
| 上 / 下 | 瀏覽畫面保存的內容 —— 指令表、分數表、製作名單。有對話框開啟時，移動它的選項 |
| F1 | 念出畫面保存的全部內容。有對話框時：正文、它顯示的內容（錄影的雙方玩家、日期和模式）以及目前選項 |
| F2 | 往回一步。有對話框時：正文和目前選項 |
| F3 | 往前一步。有對話框時：它針對所問事項顯示的內容 |
| 右搖桿（對戰中） | 按畫面上槽條的位置：左邊是 1P 體力，右邊是 2P 體力，上是 1P 能量槽，下是 2P 能量槽 |
| 按下右搖桿（對戰中） | 雙方一起：「PLAYER 1, 62%, POWER 2, PLAYER 2, 40%, POWER 1」。計時賽中則是目前的用時 |
| 右搖桿（非對戰時） | 手把上的 F1 至 F3：上相當於 F2，下相當於 F3，左右相當於 F1，按下則像 F10 一樣切換寫法。在挑戰或教學中保持如此，按下也一樣：那裡方向屬於角色，指令比槽條更重要 |
| F10 | 在五種寫法之間切換指令的念法 |
| F11，或手把上兩個搖桿同時按下 | 關閉整個朗讀器，再按一次開啟。關閉時什麼都不唸，只有這兩個按鍵仍然回應；每次啟動都是開啟狀態 |
| F7 | 停止朗讀 |
| F8 | 說出 MOD 找到的螢幕閱讀器名稱 —— 能聽到任何聲音就表示 MOD 正在運作 |
| F9 | 靜默地在記錄檔裡標記此刻：「問題在這裡」 |
| F5 | 診斷：匯出接下來的翻譯，並向影片詢問 MOD 讀不到的內容 |
| F6 | 開啟或關閉診斷記錄檔（預設開啟） |

在**生存模式**中，F1 至 F3 和右搖桿的方向會以百分比念出剩餘體力；在**計時賽**中，則以結算畫面的
格式念出目前的用時。

畫面保存的內容會停在兩端，不會繞回開頭：越過最後一段不會有聲音，退到第一段之前也不會。那份安靜
就是開頭和結尾的標記 —— 連段的各個步驟、課程的各個句子、表格的各列。作為一整塊保存的內容沒有兩
端，每次詢問都會整段念出。

**MOD 沒有自己的話。** 它說的全是遊戲的文字（保持遊戲的語言）或一個名稱。該說自己的話時 —— 按下
朗讀鍵卻沒有內容可讀、在記錄檔裡留下標記 —— 它什麼都不說，安靜就是回答。開關類的操作用遊戲自己
表示開和關的詞來回答。

## MOD 會寫入什麼

和記錄檔放在一起的 `KofXIVReader.learned` 保存著遊戲只展示一次的少數資訊：哪些角色在自訂面板裡
有服裝那一列。遊戲只在第一次需要時畫出那一列，之後再也不提，所以看見是唯一的知道方式。記下來之
後，MOD 只會慢一次，而不是每次啟動都慢。刪掉這個檔案，它會重新學一遍。

旁邊的 `KofXIVReader.settings` 保存的不是遊戲展示的內容，而是你自己的選擇：目前只有唸出指令所用
的寫法。朗讀器被關掉這件事刻意不保存——記住它的 MOD 會讓遊戲在啟動時一聲不響，又說不出原因。

## 回報問題

在遊戲裡按 **F6** 開啟記錄檔，在讀錯的那一刻按 **F9**，然後正常退出。記錄檔是遊戲資料夾裡的
`KofXIVReader.log`，上一次的會留在旁邊，名為 `KofXIVReader.prev.log`。它記錄了遊戲顯示了什麼、
寫在哪個欄位、來自哪個畫面，以及 MOD 對此說了什麼 —— 足以看出它本該說什麼。不需要你把聽到的內容
寫下來：記錄檔裡已經有準確的原文。

## 關於翻譯

這份 README 提供了遊戲支援的所有語言。只有英文和西班牙文經過母語者校對，其餘都沒有，歡迎指正：
